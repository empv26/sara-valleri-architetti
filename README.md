# Sara Valleri Architetti — Sito approvato

Portfolio di Sara Valleri Architetti, in italiano e inglese, approvato dalla cliente.

## Pubblicazione

- Codice sorgente della versione approvata: branch `main`, cartella `/docs`.
- Hosting: GitHub Pages.
- Workflow predisposto: `.github/workflows/deploy-pages.yml` (pubblicazione automatica di `/docs` da `main`).
- Dominio pubblico previsto: `www.svarchitetti.com`, con dominio e DNS amministrati su Aruba.
- Verifiche finali prima della consegna: confermare che la sorgente GitHub Pages sia impostata su **GitHub Actions**, che il CNAME `www` punti a `empv26.github.io`, che i record A del dominio principale siano quelli GitHub Pages e che la verifica DNS e il certificato HTTPS siano completati.

Le configurazioni DNS relative alla posta elettronica Aruba non devono essere alterate.
