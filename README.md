# Sara Valleri Architetti — anteprima cliente

Portfolio statico bilingue IT/EN per Sara Valleri Architetti, sviluppato da EMPV.

**Stato:** anteprima UAT non approvata per pubblicazione definitiva.

## Funzionalità
- Home fotografica a schermo intero; 4 scatti alternativi da `99 — Altro materiale`.
- Projects: griglia di 5 progetti e dettagli con galleria centrale a scorrimento, menu fisso a sinistra e testi fissi a destra (desktop).
- About: fotografia e contatti, senza biografia.
- Contact, Instagram diretto e IT/EN.

## Pubblicazione
Da repository **Settings > Pages > Build and deployment**, selezionare **Deploy from a branch**, branch `main`, directory `/docs`, quindi **Save**.

Link atteso una volta pubblicato: https://empv26.github.io/sara-valleri-architetti/

Le immagini e copertine sono una prima selezione provvisoria. Consultare `docs/config/site.json` per modificarle e scegliere l'hero Home con `?preview=1`.

**Nota:** la prima versione del sito non include i file di licenza e i sorgenti originali privati; la pubblicazione finale richiede la verifica del pacchetto approvato da Sara.
